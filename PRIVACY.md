# Política de Privacidade / Privacy Policy

**Vigência / Effective date:** 24 de julho de 2026 / July 24, 2026

## Português

O Chess Book Diagram Extractor foi projetado para funcionar localmente no
computador do usuário.

### Dados processados

- Os livros em PDF selecionados e os diagramas extraídos são processados
  somente no computador do usuário.
- O aplicativo não envia PDFs, diagramas, nomes ou caminhos de arquivos ao
  desenvolvedor ou a qualquer servidor externo.
- O aplicativo não exige conta e não utiliza anúncios, telemetria, análise de
  uso ou rastreamento.

### Verificação de atualizações

O aplicativo pode acessar a API pública e a página de Releases do GitHub para
verificar, baixar e validar atualizações. Como em qualquer conexão com um
serviço na internet, o GitHub pode receber informações técnicas comuns, como
endereço IP, data, hora e cabeçalhos da requisição. Esse tratamento é regido
pela [Declaração de Privacidade do GitHub](https://docs.github.com/pt/site-policy/privacy-policies/github-general-privacy-statement).

O desenvolvedor não recebe do aplicativo informações pessoais sobre quem
realiza essas verificações ou downloads.

### Contato

Dúvidas sobre esta política podem ser abertas na
[página de Issues](https://github.com/e-Lopes/chess-book-diagram-extractor/issues).

## English

Chess Book Diagram Extractor is designed to operate locally on the user's
computer.

### Data processing

- Selected PDF books and extracted diagrams are processed only on the user's
  computer.
- The application does not send PDFs, diagrams, file names, or file paths to
  the developer or to any external server.
- The application requires no account and uses no advertising, telemetry,
  usage analytics, or tracking.

### Update checks

The application may contact the public GitHub API and GitHub Releases to
check, download, and validate updates. As with any internet connection, GitHub
may receive standard technical information such as the IP address, date, time,
and request headers. This processing is governed by the
[GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

The developer does not receive personal information from the application
about users who perform these checks or downloads.

### Contact

Questions about this policy may be submitted through the project's
[Issues page](https://github.com/e-Lopes/chess-book-diagram-extractor/issues).
